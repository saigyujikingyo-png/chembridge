## Native result

**R0 PASSED BOUNDED; R1 FAILED.** A distinct documented main-window New action
created a visible document with independently established ownership. Synthetic
attachment and a genuine dirty edit passed separate readback. All original
document rows and the earlier synthetic buffer were preserved at this R0 gate.

R1 created and independently observed a clean single-page empty target. One
target-close sequence then removed the protected dirty synthetic sentinel while
the intended target remained. Independent reconciliation reproduced the failure
and verified the original three rows and older synthetic buffer were unchanged.
The removed document was task-generated synthetic data; no user scientific file
was an input. No native crash was observed.

The unresolved interval includes target resolution, wrapper enumeration/release,
the close call, target reference release and the first fresh observation. The
evidence cannot identify one cause or establish a general vendor defect. The
postcondition detected failed protection; it did not prevent sentinel removal.

All native writes stopped. The adapter's two entrypoints now reject close through
an independent disabled gate before native imports and claims, even if a private
runner enables the global mutation flag. Failed intents and exact sources remain
private. No retry, automatic cleanup or vendor support message followed failure.
